Sentinel Project

Sentinel 项目介绍

一个面向 RoboMaster 机器人控制场景的嵌入式控制工程，围绕整车控制、模块解耦、多板协同和实时任务调度构建，可作为机器人电控系统的工程化开发底座。

  • STM32H723 平台
  • FreeRTOS 实时任务调度
  • BSP / Modules / Application 三层架构
  • message_center 发布订阅解耦

项目概述

Sentinel 是一个面向 RoboMaster 机器人控制场景的嵌入式控制工程，基于 STM32H723 平台构建，集成 FreeRTOS 实时任务调度、板级驱动封装、功能模块抽象和应用层控制逻辑，适用于云台、底盘、发射机构及多模块协同控制。

该项目并非单一功能 Demo，而是一套具有明确分层和较强复用能力的机器人电控框架。工程当前已经具备完整的机器人初始化、任务调度、应用消息交互、传感器接入、执行机构控制和板间通信能力，可直接作为整车控制系统的开发基础。

项目定位

  • 面向 RoboMaster 机器人电控开发
  • 适用于英雄、步兵、哨兵等具备云台、底盘、发射机构的机器人平台
  • 支持单板、双板以及扩展多板协同控制
  • 适合作为比赛项目、电控框架、嵌入式课程设计和二次开发底座

核心特点

1. 清晰的三层架构

项目采用 BSP -> Modules -> Application 三层结构：

  • bsp 层负责外设和底层硬件抽象
  • modules 层负责电机、传感器、通信、算法等可复用功能模块
  • application 层负责机器人业务逻辑与整车行为控制

这种分层方式降低了代码耦合度，便于维护、移植和团队协作，也让新增功能可以在不破坏整体结构的前提下快速接入。

2. 发布-订阅式消息机制

项目内置 message_center 消息中心，应用之间通过发布/订阅进行数据交互，而不是直接相互依赖。

这意味着：

  • 云台、底盘、发射、指令处理模块彼此解耦
  • 控制链路更清晰，便于扩展新功能
  • 更适合多任务并发和多人协作开发

3. 面向机器人整车控制的应用封装

应用层已经划分出完整的机器人核心控制单元：

  • robot_cmd：统一处理遥控器、键鼠、视觉等控制输入
  • gimbal：负责云台姿态控制与反馈
  • chassis：负责底盘运动学解算与运动控制
  • shoot：负责摩擦轮、拨盘、弹仓盖等发射机构控制
  • robot：统一完成整车初始化与任务调度

这种组织方式使整车逻辑清晰，便于快速搭建完整控制链。

4. 支持单板/双板协同部署

项目通过条件编译支持不同板型配置，当前代码中已经提供：

  • ONE_BOARD 单板控制
  • CHASSIS_BOARD 底盘板
  • GIMBAL_BOARD 云台板

适合将云台、底盘、裁判系统、遥控输入等功能分配到不同控制板，实现更灵活的整车部署。

5. 面向实战的通信与模块扩展能力

项目不只关注电机控制，还集成了机器人比赛和工程调试中常见的通信链路与功能模块，具备较强扩展性。

主要功能

1. 底层外设与板级支持

bsp 层已经封装多类硬件接口，便于上层模块直接复用：

  • CAN
  • USART / UART
  • SPI
  • IIC
  • USB
  • ADC
  • PWM
  • GPIO
  • Flash
  • DWT
  • Log

这些基础能力为电机、传感器、上位机通信和调试工具提供了统一支撑。

2. 电机与执行机构控制

项目支持多类机器人关键执行机构控制，包括：

  • 云台 yaw / pitch 电机控制
  • 底盘多电机协同控制
  • 发射机构摩擦轮与拨盘控制
  • 弹仓盖舵机控制
  • DJI 电机与 DM 电机接入

可直接服务于云台控制、底盘驱动和发射机构控制等核心任务。

3. 传感器与状态感知

项目已集成多类常用感知模块：

  • IMU 姿态解算
  • BMI088 相关惯导支持
  • TFminiPlus 测距模块
  • 编码器反馈
  • 裁判系统数据接入

这些模块为姿态闭环、速度反馈、目标感知和整车状态判断提供基础数据。

4. 多源控制输入融合

robot_cmd 模块能够统一处理多种控制来源，并将其转换为具体控制指令：

  • 遥控器输入
  • 键盘鼠标输入
  • 视觉控制输入
  • 上位机控制数据

这使项目既能满足人工操作，也能接入自动瞄准、上位机联调和半自动控制场景。

5. 机器人比赛相关功能

项目已包含 RoboMaster 场景下常见的比赛功能支持：

  • 裁判系统通信
  • 裁判系统 UI 刷新
  • 板间 CAN 通信
  • 主从控通信
  • 超级电容模块支持
  • VOFA 数据可视化调试

对于比赛型机器人来说，这些能力能显著减少从零开发的工作量。

软件架构亮点

应用层

负责整车行为组织和控制逻辑实现，重点体现为：

  • 指令解析
  • 模式切换
  • 运动控制
  • 发射控制
  • 状态反馈

模块层

负责沉淀可复用能力，当前包含：

  • 电机模块
  • IMU 模块
  • 遥控模块
  • 裁判系统模块
  • 消息中心模块
  • 守护模块
  • 超级电容模块
  • 蓝牙模块
  • OLED 模块
  • 通信协议模块

BSP 层

负责统一底层硬件接口，为上层屏蔽具体芯片外设差异，降低移植成本。

项目优势

  • 架构清晰，适合中大型机器人电控项目持续迭代
  • 模块解耦明显，便于多人协同开发
  • 支持多任务调度，适合实时控制场景
  • 兼容单板与双板部署，工程适应性强
  • 集成比赛常用功能，落地性强
  • 同时具备控制、通信、调试、扩展四类能力

适用场景

  • RoboMaster 机器人整车控制开发
  • 云台/底盘/发射机构一体化控制项目
  • 机器人电控框架搭建
  • 嵌入式控制系统课程设计与实验项目
  • 需要多模块协同和高复用结构的 STM32 项目

总结

Sentinel 是一套面向机器人实战场景构建的嵌入式控制工程。它不仅具备云台、底盘、发射机构等核心功能，还通过三层架构、消息中心、多板协同和模块化封装，形成了较强的工程化能力。对于需要快速搭建机器人控制系统、同时兼顾扩展性与维护性的项目而言，Sentinel 具备较高的参考和使用价值。
